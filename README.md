# Marcenaria Langner | Móveis Sob Medida & Alta Marcenaria

Landing page de alta conversão para marcenaria fina, móveis sob medida e ambientes planejados de alto padrão (Cozinhas Gourmet, Dormitórios, Closets Inteligentes, Home Theaters, Painéis Ripados e Ambientes Corporativos).

## 🚀 Tecnologias & Destaques
- **HTML5 Semântico:** SEO otimizado para marcenaria e móveis sob medida, OpenGraph, microdados e tags de conversão.
- **CSS3 Moderno:** Paleta nobre e quente (Madeira Nogueira `#242119`, Ouro Champanhe `#C89B3C` / `#E0D29E` e Creme Marfim), design responsivo e microinterações fluidas.
- **JavaScript Modular Puro:** Triagem inteligente em 1 clique direcionada para o WhatsApp com pré-formatação do tipo de ambiente desejado, contadores animados e accordion FAQ técnico.
- **Imagens Otimizadas:** Fotografia de alto padrão para ambientes planejados e identidade visual da marca integrada.

## 📦 Como Subir na Vercel
1. Acesse [vercel.com/new](https://vercel.com/new);
2. Conecte sua conta do GitHub e selecione o repositório `site-marcenaria`;
3. Mantenha as configurações padrão (Framework Preset: **Other**) e clique em **Deploy**;
4. Seu site estará no ar em segundos com certificado SSL gratuito e CDN global ultra-rápida!

## ⚙️ Personalização do WhatsApp
Para alterar o número do WhatsApp comercial dos projetistas:
Abra o arquivo `script.js` e altere a constante `WHATSAPP_PHONE` na linha 8 com o seu número com DDD (ex: `5511999999999`).
